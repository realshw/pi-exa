# pi-exa

[Exa](https://exa.ai) MCP tools for [pi](https://pi.dev): `web_search_exa` (web search) and `web_fetch_exa` (bounded page content as markdown).

## Install

```bash
pi install git:github.com/realshw/pi-exa
```

Or try it without installing: `pi -e git:github.com/realshw/pi-exa`. Restart pi (or `/reload`) afterwards.

## Config

- `EXA_API_KEY` — your Exa API key (https://dashboard.exa.ai/api-keys), lifts the free-tier rate limit.

## Dev

```bash
npm install
```
